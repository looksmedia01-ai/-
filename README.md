# Mascot Showreel (Remotion, 17s, 9:16)

표정 PNG(`public/expressions/`)를 장면마다 갈아 끼우고, 몸 전체를 늘이기·누르기·튀기기·기울이기로 연기시키는 17초 세로 쇼릴.
1080×1920, 30fps, 510프레임. 120BPM 배경음악 포함.

## 장면 (박 단위, 컷 = 마디 첫 박)

120BPM 박자 그리드(1박 = 15프레임, 1마디 = 60프레임)에 맞춰 장면 길이를 박 단위로 정의한다. 이름표는 한글(Jua 폰트)로 화면 아래쪽에 나온다.

| # | 이름 | 박 | 프레임 | 얼굴 PNG | 몸 연기 | 효과 |
|---|------|----|--------|----------|---------|------|
| 1 | 기본 | 4 | 0–60 | neutral | 낙하 → 2박 착지 → 3박 튕김 → 4박 인사 기울이기 | 착지 흔들림 |
| 2 | 눈감음 | 4 | 60–120 | happy | 팝 → 박마다 좌우로 흔들며 깡충 | Zzz |
| 3 | 놀람 | 4 | 120–180 | surprised | 컷 박에 화들짝 점프 → 2박 착지 → 젖히고 덜덜 | 집중선, 흔들림, 땀방울 |
| 4 | 웃음 | 4 | 180–240 | laugh | 박마다 깡충 3번 → 젖히고 킥킥 | 웃음 눈물, 착지 흔들림 |
| 5 | 옆눈질 | 4 | 240–300 | curious | 1박 목 쭉 → 3박 갸웃 → 제자리 | — |
| 6 | 울상 | 4 | 300–360 | surprised* | 풀썩 주저앉아 박마다 "흑" 흐느낌 | 흘러내리는 눈물, 비구름 |
| 7 | 땀 | 10 | 360–510 | curious* → neutral → happy | 진땀 흘리며 덜덜 → 꿀꺽 → 웅크림 → 도약·공중회전 → 480(마디 첫 박) 쾅 착지 | 박마다 늘어나는 땀방울, 색종이, 강한 흔들림 |

\* 울상·땀은 전용 PNG가 없어서 기존 얼굴에 몸 연기와 효과를 더해 만든다. 전용 PNG가 생기면 `public/expressions/`에 넣고 `src/timeline.ts`의 `EXPRESSIONS`와 `src/Showreel.tsx`의 `BOUNDS`/`ALL`에 추가하면 된다.

장면 길이는 `src/timeline.ts`의 `SCENE_DEFS[].beats`만 바꾸면 시작 프레임·총 길이가 자동 계산된다(4의 배수면 컷이 마디 첫 박).

## 효과 (`src/effects.tsx`, 랜덤 없이 프레임 기준)

파티클 값은 `spread(i, salt)` 결정적 해시로만 정한다(`Math.random` 없음). 같은 프레임은 몇 번 렌더해도 같은 결과.
흔들림 타이밍·세기는 `IMPACTS`, 땀방울 위치·구간은 `SWEAT`. 눈물·땀방울은 캐릭터 레이어 안에 있어서 몸과 같이 늘어나고 기운다.

## 배경음악 (`scripts/make-bgm.mjs` → `public/bgm.wav`)

120BPM C장조, 외부 샘플 없이 코드로 합성. 노이즈도 시드 고정이라 매번 같은 파일이 나온다.

| 마디 | 장면 | 음악 |
|------|------|------|
| 0 | 기본 | 기본 그루브 (박마다 킥 = 착지) |
| 1 | 눈감음 | 크래시로 진입, Am |
| 2 | 놀람 | 스톱 타임: 1박 "빵!" → 2박 착지 "쿵" → 정적 속 트릴 |
| 3 | 웃음 | 16분 하이햇으로 들뜬 그루브, 깡충마다 킥 |
| 4 | 옆눈질 | 드럼 빠짐, 3박 갸웃에 F → Fm "음?" |
| 5 | 울상 | 슬픈 트롬본 "빠-밤-빠-밤~" (흐느낌과 같은 박) |
| 6 | 땀 | 째깍거리는 하이햇 + 반음씩 기어오르는 마림바, 박마다 땀방울 "똑" |
| 7 | 땀 → 피날레 | 1·2박 움찔 히트 → 3박 도약부터 상승 아르페지오 + 스네어 롤 |
| 8 첫 박 | 착지 | 크래시 + 큰 C 코드 "쾅!" |

장면 길이를 바꾸면 이 파일의 마디 배치도 함께 고친 뒤 `npm run bgm`으로 다시 생성한다.

## 실행

```bash
npm install
npm run bgm      # 배경음악 생성 (public/bgm.wav, 이미 포함됨)
npm run dev      # Remotion Studio 미리보기
npm run render   # out/showreel.mp4
```

- 화면 크기·캐릭터 위치: `src/layout.ts`
- 연기 키프레임: `src/timeline.ts` (`acting()` — 장면별 x / y / stretch / rot / spin)
- 가로 스케일은 부피 보존으로 자동 계산(`sx = 1 + (1 - stretch) * 0.8`), 기울기는 발밑 기준, 공중회전은 몸 중심 기준
- 표정마다 캐릭터 위치가 몇 px씩 달라서 `BOUNDS`로 정렬해 교체 시 튀지 않게 함
